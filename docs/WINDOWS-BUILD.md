# بناء نسخة ويندوز — دليل خطوة بخطوة

## لماذا لا يمكن بناؤها من الماك

مثبِّت ويندوز يحتاج **بناءً على جهاز ويندوز نفسه**. السبب ليس Electron — بل خدمة
بايثون: أداة PyInstaller التي تحوّلها إلى ملف تنفيذي **لا تدعم البناء المتقاطع**
إطلاقاً. ملف `egco-api.exe` يجب أن يُبنى على ويندوز.

النتيجة: انقل **مجلد المشروع** إلى جهاز الويندوز وابنِ هناك (مرة واحدة، ~٢٠ دقيقة).

---

## المتطلبات على جهاز الويندوز

| البرنامج | النسخة | ملاحظة |
|---|---|---|
| **Node.js** | ٢٠ أو أحدث | nodejs.org — النسخة LTS |
| **Python** | ٣٫٩ أو أحدث | python.org — **فعّل «Add Python to PATH»** أثناء التثبيت |
| مساحة | ~٢ جيجابايت | للتبعيات ومخرجات البناء |

> **الخط العربي:** ثبّت خط **Cairo** (مجاني من Google Fonts) لتطابق الواجهة التصميم
> تماماً. بدونه يعمل التطبيق ويظهر العربي بخط Segoe UI — سليم لكنه ليس خط التصميم.

## الخطوات

### ١. انقل المشروع
انسخ مجلد `Dashboard` كاملاً إلى جهاز الويندوز — **باستثناء** هذه المجلدات
(ستُبنى من جديد، ونسخها يسبب أخطاء لأنها تحوي ملفات ماك ثنائية):

```
node_modules/
services/api/.venv/
services/api/dist/
services/api/build/
release/
```

### ٢. افتح PowerShell في مجلد المشروع ونفّذ

```powershell
npm install
npm run setup
```

`setup` ينشئ بيئة بايثون ويثبّت تبعيات الخدمة. إن ظهر خطأ «python غير معروف»
فأعد تثبيت بايثون مع تفعيل خيار **Add Python to PATH**.

### ٣. تحقق قبل البناء

```powershell
npm run test:api
```

يجب أن ترى **51 passed**. لو فشل شيء هنا فالمشكلة في البيئة لا في الكود — أصلحها
قبل المتابعة.

### ٤. ابنِ المثبِّت

```powershell
npm run package
```

المخرجات في:
```
release\EGCO-Dashboard-0.1.0-setup.exe
```

### ٥. ثبّت وشغّل
شغّل ملف `setup.exe`. ويندوز قد يعرض «Windows protected your PC» لأن الملف غير
موقَّع رقمياً — اضغط **More info ← Run anyway**. (نفس سبب تحذير الماك: التوقيع
الرقمي يحتاج شهادة مدفوعة.)

## نقل بياناتك إلى جهاز الويندوز

قاعدة البيانات ملف واحد محمول تماماً — **جُرّب فعلياً**.

**من الماك**، انسخ:
```
~/Library/Application Support/egco-dashboard/egco.db
```

**إلى ويندوز**، ضعه في:
```
%APPDATA%\egco-dashboard\egco.db
```

(الصقه في شريط عنوان مستكشف الملفات: `%APPDATA%\egco-dashboard`)

انسخه **والتطبيق مغلق**. عند التشغيل التالي ستجد كل الموردين والكشوفات كما هي —
وسيُرقّي التطبيق القاعدة تلقائياً إن لزم.

للبدء من بيانات نظيفة: لا تنسخ شيئاً، سينشئ التطبيق قاعدة فارغة.

## ما جُهِّز مسبقاً ليعمل على ويندوز

| البند | الحالة |
|---|---|
| أوامر البناء (`build:api` · `test:api` · `dev:api`) | ✅ تعمل على النظامين عبر `scripts/py.mjs` |
| مسار بايثون (`Scripts\python.exe`) | ✅ مُعالَج |
| تشغيل الخدمة من داخل التطبيق المحزوم (`egco-api.exe`) | ✅ مُعالَج |
| نافذة الطرفية السوداء | ✅ مُعطّلة على ويندوز |
| مثبِّت NSIS بواجهة عربية | ✅ مُهيّأ في `electron-builder.yml` |
| الخطوط العربية | ✅ بدائل ويندوز مضافة (Segoe UI · Tahoma) |

## البديل: بناء آلي عبر GitHub Actions

إن أردت مثبِّتات ويندوز وماك بضغطة واحدة دون تثبيت أدوات على كل جهاز، يمكن إعداد
GitHub Actions يبني الاثنين عند كل إصدار. يحتاج رفع الكود إلى مستودع GitHub —
**البيانات لا تُرفع، الكود فقط.** أخبرني إن أردت ذلك.
