# المشحون — ماذا وصل جهازك، ومتى، وكيف تحقّقنا

يُكتب السطر **بعد** الشحن لا قبله. عمود «كيف تحقّقنا» ليس زينة: «تم» ليست إثباتاً،
وبيانات حقيقية وحدها هي الإثبات في تطبيق تُبنى عليه قرارات مالية.
